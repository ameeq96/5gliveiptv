Practical guide

Build a playlist that works on a smaller screen

A long list that is manageable with a television remote can feel awkward on a phone. Use the player's documented organisation tools to make navigation easier without replacing a working setup with unknown sources.

Keep the first screen useful

If supported, save a small favourites list and check text size or orientation options. Only organise sources you are authorised to use; a renamed category does not change your plan allowance or access rights.

Refresh deliberately

Record the current configuration privately before changing it, then test one documented refresh. Avoid doing this while repeatedly switching networks. If the result is unexpected, note the device and player version, and keep playlist addresses out of public messages.
